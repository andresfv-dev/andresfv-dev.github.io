# Portafolio

Stack:
- Vite + React
- Tailwind CSS
- Lucide React

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy (GitHub Pages)

Este repo incluye un workflow en `.github/workflows/deploy.yml` que compila y publica `dist/` en GitHub Pages cuando haces push a `main` o `master`.
